## Getting a DOI (optional, one-off)

1. Sign in to https://zenodo.org with the GitHub account.
2. Settings -> GitHub -> flip the switch for this repository.
3. On GitHub, draft a new release (or edit `v1.0`) and publish it; Zenodo mints a DOI automatically.
4. Add the DOI badge to the top of README.md and, if desired, one sentence in the paper's Data availability section.
